# Evaluation data

| File | What it is |
|---|---|
| `build_questions.py` | Source of the question set. Each answerable item names its gold PDF page(s) and a gold quote copied from that page |
| `questions.jsonl` | Generated by `build_questions.py` |
| `dataset.verified.jsonl` | Items that passed `scripts/verify_eval_set.py`. The evaluator reads only this file |
| `reports/` | Output of `scripts/evaluate.py` (JSON + Markdown) |

The current set has 51 items:

- 32 English answerable questions across 19 articles: plant disease, soil fertility, nutrition,
  salinity, solarization, irrigation, pollination, IPM, organic production, horticulture.
- 10 Bangla versions of those questions, for cross-lingual retrieval.
- 11 questions the book cannot answer, for abstention. Two other candidates were rejected by the
  verifier because their key terms occur in the book.

Verification is mechanical:

- An answerable item is kept only if each gold quote occurs, normalised for whitespace and
  ligatures, on one of its gold pages.
- An unanswerable item is kept only if none of its key terms occurs anywhere in the book.

## Adding items

1. Open the PDF at the page, copy a sentence exactly, and add a tuple to `ANSWERABLE` with that page.
2. Run `python eval/build_questions.py && python -m scripts.verify_eval_set ../Book/Agriculture.pdf`.
   Rejected items are printed and excluded.

## Vision set (`vision/manifest.jsonl`)

Not included: the repository has no labelled plant-disease photos. Add your own (or a licensed
public set such as PlantVillage) as `eval/vision/<file>.jpg`, with one line per photo:

```json
{"image": "tomato_late_blight_01.jpg", "expected": "diagnose", "label_terms": ["late blight", "Phytophthora"], "lang": "en"}
{"image": "blurry_01.jpg", "expected": "abstain"}
```

`python -m scripts.evaluate vision` then reports:

- `candidate_hit@3`: a label term appears among the top 3 cited candidates.
- Abstention on diagnosable photos.
- Abstention on unusable photos.

Without a manifest it reports "not run" instead of a number.
